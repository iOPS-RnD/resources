== Introduction

iOPS is a research and development initiative supporting intelligent and reliable power-system operation, with a focus on operational analysis, decision support, semantic technologies, AI and the control room of tomorrow.

This repository contains material that can be reused across more than one iOPS project.

== Purpose

This repository supports iOPS by collecting material that more than one project can use, so that projects build on shared definitions, data and knowledge instead of repeating them. Each section below states what belongs in it.

== Scope

=== What belongs here

* common documentation
* common diagrams
* reusable templates
* training material
* public presentations
* example data and synthetic data
* ontology and schema examples
* CIM-related resources
* shared specifications
* common architecture material
* branding for the initiative and its projects

=== What does not belong here

* project-specific source code, which stays in the project's own repository
* project-specific research results, unless they have deliberately been promoted to a shared resource
* programme-management or other non-public information, which belongs in the private management repository
* credentials, tokens, passwords, keys or other secrets

== Relationship to iOPS

iOPS is an umbrella research and development initiative. This repository holds the resources its projects share. The projects and shared research assets are listed under link:projects/README.adoc[Projects], and the link:https://github.com/iOPS-RnD[organisation profile] introduces the initiative.

== Key Standards and Technologies

This work leverages the following key standards and technologies:

* *Common Information Model (CIM)*: standards IEC 61970, IEC 61968 and IEC 62325.
* *Graph databases and queries*: storing and querying CIM-based power-system models as graphs.
* *AI and natural language processing (NLP)*: large language models applied to power-system data.
